# 注意力花园 · Attention Garden

一件探索**生成式 AI、注意力经济与计算基础设施**关系的交互式数字生态艺术作品。
生成对象作为"种子"涌入信息流；注视是它们唯一的养分——被看见的成长、分枝、落籽、聚成潮流，久无人问津的转入休眠直至化为数字残骸；花园之下，一套由采集、传输、排序、推理与能源构成的**代谢根系**持续运转。

单文件实现（`index.html`），无外部依赖，双击即可打开。

## 展厅设计原则（v3）

作品面向展厅无人值守运行，三条硬约束贯穿全部交互：

**一、不需要点击。** 移动鼠标即是注视：悬停在对象上就是喂养，停下即自动展开档案卡，无需任何点击动作。

**二、无人时算法接管。** 闲置 12 秒后进入「**算法注视 ALGORITHMIC GAZE**」——一束冷色的目光自行在花园与信息流中游走浇灌，相机也自动巡游（长时间停在地表，间或下潜到排序层与能源层）。观众一移动鼠标，立即切换为暖色的「**观众注视 VISITOR GAZE**」并消耗其有限的注意力。这既解决了展厅的自运行问题，也正是作品的论点：机器的注意力无限，人的注意力有限。

**三、花不会随便消失。** 缺乏注意力的植株不会猝死，而是先褪色**休眠 DORMANT**（站立、打盹、可被注视唤醒），只有长时间无人问津才最终倒伏。平台还会给所有内容分配一份基础曝光涓流，让花园长期保持繁盛。真正导致凋零的只有一件事——**潮流退去**。

## 两个功能页面

### Ⅰ 信息爆炸 INFORMATION BLOOM
无限画布上的生成内容信息流（参考：文字漩涡拼贴 / 相册彩色时间线 / 作品分布等高线地图）。

- 移动鼠标即注视喂养，拖拽平移，滚轮缩放；停在对象上自动展开档案
- 获得关注的对象繁殖变体，形成带日期标注的**谱系彩线**
- 注意力 ≥42 自动迁入花园，成为那里的一粒种子（**无需手动收藏**）
- 闲置时相机缓慢巡游，展示画布尺度

### Ⅱ 注意力花园 SYNTHETIC GARDEN
定宽花园（观众永不会拖到空白处），相机只做垂直移动：天空 ⇄ 地表 ⇄ 地下代谢五层。

**物种图鉴**——八个命名物种，形态 / 色系 / 画作风格三位一体，同种花天然同貌同色：

| 物种 | 形态 | 色系 |
|---|---|---|
| 十字菀 CROSSVANE | 长舌双层辐射 | 砖红 |
| 铃钟兰 BELLNET | 垂挂三钟 | 雾蓝 |
| 穗序草 SPIKELET | 递减花序 | 苔绿 |
| 伞形藻 UMBRELLE | 细梗顶盘 | 青瓷 |
| 涡卷莲 SPIRALIS | 手绘同心环 | 藕紫 |
| 蝶尾菊 PAPILIO | 不对称双翼 | 玫粉 |
| 流苏柳 FRINGEA | 垂坠丝线 | 赭黄 |
| 墨点兰 INKSPOT | 疏密圆点群 | 墨石 |

绘制语言为**纸艺剪纸**：扁平色块、双层错位套印（riso 味）、细墨线描边，每朵花只用两色 + 纸底；花心是一幅略微倾斜装裱的生成画作。

- **九阶段慢生命周期**：种子 → 发芽 → 幼株 → 拔节 → 含苞 → 初绽 → 繁盛（长出分枝小花）→ 群落 → 迟暮
- **潮流 TREND**：同种 ≥3 株开花即成簇——地面光柱、光尘、同色系蝴蝶、潮流旗标；成员之间**互哺注意力**自我维持。升格为「群落」必须先成潮流；**潮流退去 42 秒后**才进入迟暮，潮流回归则复苏
- **落籽繁衍**：繁盛期起自动落籽，同种后代就近生根，群落自然扩张
- **自动补种**：种群低于 15 株时自动补种，优先让信息流迁入的对象落地
- 四排景深种植，前后错落；远山两重、纸剪云、太阳同心环

### Ⅲ 地下代谢 COMPUTATIONAL METABOLISM
根系即基础设施，五层剖面按数据与能源的真实流转分层：

| 深度 | 层位 | 内容 |
|---|---|---|
| −0 m | 采集层 CAPTURE | 每株的递归分形根系（曝光／停留／点击 → 行为信号） |
| −57 m | 传输层 TRANSPORT | 网关路由、请求分发、骨干互联 |
| −122 m | 排序层 RANKING | 数据集机架、缓存命中、推荐排序、交换总线 |
| −202 m | 推理层 INFERENCE | GPU 集群（显存负载条、温度、热浪、液冷） |
| −282 m | 能源层 POWER | 变电站、供电干线、液冷循环与风扇 |

三种脉冲沿真实链路流动：**信号↓**（金）从根系经网关抵达算力核；**数据↔**（蓝）在机架与 GPU 之间往返；**电力↑**（红）自变电站供向算力。注视任意节点即展开代谢档案（吞吐、命中率、显存、温度、功率）；底部实时给出累计能耗与 CO₂e 估算。

## 接入真实图片（下一步爬取的数据）

编辑 `assets/manifest.js`：

```js
window.ATTENTION_GARDEN_IMAGES = [
  'assets/images/0001.jpg',
  'assets/images/0002.jpg',
  // …爬取的图片路径或允许跨域的 URL
];
```

信息流对象与花心画作会自动改用真实图片；无法加载时回退为内置九种程序化纹样（十字绣 / 文字漩涡 / 线绘细胞 / 相册小照 / 织锦方格 / 同心圆环 / 剪纸花卉 / 层叠色条 / 卵石标本），每个物种绑定其中一种，保证同种同貌。

## 部署上线

打包成可上传的目录，再传到 HKUST iHost：

```bash
bash tools/build_site.sh      # → dist/public_html/
bash tools/deploy_ihost.sh    # 需先连 HKUST VPN
```

详见 [DEPLOY.md](DEPLOY.md)（含 FileZilla 手动上传步骤与排错）。

## 调试参数

`?skip=1` 跳过开场 · `&page=garden` 直达花园 · `&cam=430` 相机深度 · `&warp=140` 花园快进秒数 · `&gaze=visitor` 强制观众模式 · `&vt=1` 虚拟时间驱动（无头截图用）· `&probe=1` 标题栏输出生态计数
