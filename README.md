# 注意力花园 · Attention Garden

一件探索**生成式 AI、注意力经济与计算基础设施**关系的交互式数字生态艺术作品。
生成对象作为"种子"涌入信息流；你的注视是它们唯一的养分——被看见的成长、分枝、结籽、聚成潮流，无人问津的沉为数字残骸；花园之下，一套由采集、传输、缓存、计算与能源构成的**代谢根系**持续运转。

单文件实现（`index.html`），无任何外部依赖，直接双击或本地静态服务打开即可。

## 两个功能页面

### Ⅰ 信息爆炸 INFORMATION BLOOM
无限画布上的生成内容信息流（参考：文字漩涡拼贴 / 相册彩色时间线 / 作品分布等高线地图）。

- **拖拽**平移 · **滚轮**缩放（无限画布）
- **悬停**注视 = 喂养对象（消耗你的注意力）
- **点击**查看生成对象档案，可 **✚ 收藏为种子** 送入花园种子架
- 注意力 ≥42 的对象会自动"迁入花园"
- 获得关注的对象繁殖变体，形成带日期标注的**谱系彩线**
- `信息风暴 STORM` 按钮：生成速率 ×6

### Ⅱ 注意力花园 SYNTHETIC GARDEN
能长出"图像花"的人工花园（参考：十字绣像素花窗口 / 纸艺花卉包装的物种卡）。

- **世界坐标相机**：滚轮上下潜行（地表 ⇄ 根系 ⇄ 基岩），Shift+滚轮横移，Ctrl+滚轮缩放，拖拽自由平移——土壤、根系、天空全部锚定世界，同步滚动
- **物种系统**：图像风格 × 调色板 → 六大花形家族（针脚 / 环纹 / 辐光 / 团绒 / 铃铛 / 斑斓），同种花形态颜色一致
- **十阶段生命周期**（约 6 分钟）：种子 → 发芽 → 幼苗 → 花苞 → 初绽 → 盛放 → **繁茂**（长出分枝小花）→ **结籽**（种荚落籽、原地繁殖同种）→ 迟暮（缓慢落瓣）→ 凋零（化为残骸与养分）
- **潮流群落**：同种 ≥3 株聚集 → 地面光晕、光尘、**同色系蝴蝶**、潮流旗帜；≥5 株 → 光柱、更多蝴蝶，愈发璀璨
- **种子架**：点选种子（收藏所得或随机种子包）→ 点击土壤播种；支持前后双排景深种植
- 悬停浇灌注意力；点击植株看**物种档案**（作品、物种、阶段、分枝、落种、能耗）

### Ⅲ 地下代谢 COMPUTATIONAL METABOLISM（花园下潜）
根系即基础设施，五层剖面：

| 深度 | 层位 | 内容 |
|---|---|---|
| −0 m | 表土 · 行为采集 | 每株的细根须（曝光/停留/点击 → 信号） |
| −74 m | 输送 · 数据传输 | 主干根汇流 + 路由节点 + 骨干虚线 |
| −218 m | 缓存 · 排序引擎 | 缓存/推荐排序腔室 |
| −362 m | 计算 · 模型推理 | GPU 算力核（负载、热浪、液冷环路） |
| −530 m | 能源 · 冷却循环 | 变电站、电网金色脉络、冷却水流 |

- 金色脉冲 = 注意力信号下行；青色脉冲 = 能量回流上行；凋零植株沉降**残骸脉冲**
- 点击任意节点查看**代谢档案**（吞吐、命中率、负载、温度、功率、累计能耗）
- 右侧深度仪实时显示所在层位

## 接入真实图片（下一步爬取数据）

编辑 `assets/manifest.js`：

```js
window.ATTENTION_GARDEN_IMAGES = [
  'assets/images/0001.jpg',
  'assets/images/0002.jpg',
  // …爬取的图片路径或允许跨域的 URL
];
```

信息流对象与花朵中心会自动改用真实图片（按主色自动归入调色板物种）；无法加载时回退为内置的九种程序化纹样（十字绣 / 文字漩涡 / 线绘细胞 / 相册小照 / 织锦方格 / 网点圆盘 / 剪纸花卉 / 层叠色条 / 卵石标本）。

## 调试参数

`?skip=1`（跳过开场）`&page=garden`（直达花园）`&camy=430`（相机深度）`&warp=120`（花园快进秒数）`&vt=1`（虚拟时间驱动，供无头截图）`&probe=1`（标题栏输出生态计数）

## 结构

```
index.html          # 全部作品（样式 + 两页逻辑，无外部依赖）
assets/manifest.js  # 真实图片清单（可选）
assets/images/      # 放置爬取图片（自建）
```
