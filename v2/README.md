# v2 · 形态即数据

v1（NeurIPS Creative AI Track 接收版，`c31cc60`）的花朵形态是预设的十四种。
v2 要把形态变成**从数据长出来的**：每朵花有一个基因组，基因组由
它那张图的视觉特征 + 它在展场里被怎么对待，共同决定。

目标不是更好看，是**忠实**——观众应该能把形态读回数据。

## 架构：三层分离

```
        图像特征 + 互动数据
                ↓
        ┌───────────────┐
        │   基因组       │  16–24 个浮点数，确定性生成
        │   GENOME      │  同一份数据永远长出同一朵花
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │   生长器       │  纯函数：基因组 → 抽象骨架
        │   GROWER      │  （花瓣的三维变换 / 轮廓 / 颜色）
        └───┬───────┬───┘
            ↓       ↓
     ┌──────────┐ ┌──────────────┐
     │ 2D 渲染器 │ │  3D 渲染器    │
     │ canvas   │ │  three.js    │
     │ 几百朵    │ │  一次一朵     │
     │ 实时生态  │ │  标本视图     │
     └──────────┘ └──────┬───────┘
                         ↓
                   ┌──────────┐
                   │ STL 导出  │ → 3D 打印
                   └──────────┘
```

**为什么这样分**：实时生态需要几百朵花同时跑，只能 2D；
"标本视图"一次只看一朵，可以上三维实时渲染；3D 打印需要真实几何。
三者共用同一个基因组和同一个生长器，所以 2D 里的那朵花和
3D 里的那朵花、打印出来的那座雕塑，**是同一个生物**。

## probe/ —— 可行性探针（2026-10-22）

不是产品代码，是用来回答"二维到底能不能做到 Blender 那种参数化异形建模"的。
结论：**能**，而且三维与 STL 导出也通了。

| 文件 | 做什么 |
|---|---|
| **`genome-lace.html`** | **当前方向**。线构成的花：蕾丝筋脉 + 串珠 + 弧射花丝。<br>双击即可看，加 `?dark=1` 看暗场 |
| `genome-2d.html` | ~~实体块面版~~ 已废弃，留作对照。方向错误：胖、不透光 |

| `view-3d.html` | three.js 读回 STL 渲染预览（需起本地服务器 + three.js） |
| `sample_flower_263.stl` | 一个样本，可直接拖进切片软件或 Blender 看 |

### 形态语言（2026-10-22 据参考图修正）

参考图的共同语言是**线、丝、珠构成的通透结构**，不是实体块面：
缠线的蕾丝花瓣、激光切的镂空薄片、串珠的放射臂、层叠的波浪叶。

| 原则 | 落到代码里 |
|---|---|
| 轮廓优先，线构成面 | 花瓣只描边 + 极淡填充，内部是从基部放射的筋脉 |
| 重复的可数小单元 | 边缘珠、筋脉、花丝——**数量直接编码数据** |
| 纤细通透 | 全程 stroke，负空间与正形同等重要 |
| 浅色低饱和 | 饱和压到 0.16–0.46；暗场时提亮并加饱和 |
| 中轴 + 放射 + 悬垂 | 缠线茎 + 径向花瓣 + droop 基因 |

**线和珠比块面更适合做数据可视化**——它们是可数的。
珠子数量＝点赞数，筋脉数＝图像复杂度，花丝数＝互动量。观众能数出来。

### 探针验证到的事实

- 2D canvas 可以做径向对称、开合角、多层轮生、前后遮挡（画家算法）
- 花瓣在**三维里算**、投影到二维画——所以 2D 和 3D 是同一套骨架
- 编织/网格填充能做出"代码质感"，像素量化能接上 v1 的视觉语言
- 基因 → 实体网格 → STL 全程纯数学，**不需要 GPU、不需要 Blender、不需要 Unity**
- 实测：6112 三角面、约 120 mm 高、最薄壁 3.2 mm，FDM 可打

### 探针**没有**验证的事

- 没有接真实数据（基因是随机的，不是从图像特征来的）
- 没有做布尔并集——花瓣与花心是互相穿插的独立闭合体。
  多数切片软件能正确处理，但没在真机上验证过
- 没有考虑打印支撑、悬垂角、薄壁强度
- 形态的"可读性下限"没有约束：极端基因会长出看不懂的东西

## 运行

```bash
# 2D：直接双击 probe/genome-2d.html

# 3D → STL
cd v2/probe && node genome-to-stl.js

# 3D 预览（需要 three.js）
npm install three@0.169.0
python3 -m http.server 8711     # 另开一个终端
# 浏览器访问 http://localhost:8711/view-3d.html
```
